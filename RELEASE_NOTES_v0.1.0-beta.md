# ⚡ FastDownloader Pro v0.1.0 (Beta) — Feature Update

FastDownloader Pro is an ultra-fast, lightweight, open-source download manager featuring IDM/XDM-grade multi-connection chunking, automatic media extraction, and seamless browser integration.

---

### 🌟 What's New in this Release

#### 1. 📊 Floating Live Download Progress Dialog (IDM Parity)
- **16-Chunk Connection Visualizer**: Real-time visual progress bar showing all 16 parallel segmented streams downloading simultaneously.
- **Live Transfer Metrics**: 300ms high-precision updates for download speed, ETA countdown, downloaded vs. total file size, and percent.
- **Task Controls**: Dedicated **Pause**, **Resume**, **Cancel**, and **Hide** buttons.
- **On-the-Fly Speed Limiter**: Real-time bandwidth throttling dropdown directly in the progress dialog (**Unlimited**, **500 KB/s**, **1 MB/s**, **2 MB/s**, **5 MB/s**, **10 MB/s**).
- **Post-Download Automation**: Checkboxes to *"Open file when complete"* and *"Turn off computer when done"*.

#### 2. 🎉 Download Complete Action Popup
- Immediate popup upon 100% download completion with Windows audio chime.
- **`[ 🚀 Open ]`**: Runs/executes the downloaded file with a single click.
- **`[ 📁 Open Folder ]`**: Opens Windows Explorer and automatically highlights the exact downloaded file (`/select`).
- **`[ ✕ Close ]`**: Dismisses the notification.

#### 3. 🎯 Smart Pre-Flight Confirmation Dialog
- Desktop modal for intercepted and added downloads.
- Allows editing destination folder, customized file name, and automatic category routing (**General**, **Compressed**, **Programs**, **Video**, **Music**, **Documents**).
- One authoritative dialog with zero duplicate web popups.

#### 4. 🎬 Floating In-Page Video Download Bar (Companion Extension)
- Interactive hover widget **`[ 🎬 Download this video ▼ ]`** automatically docked above playing videos on **YouTube**, **Facebook**, **Twitter/X**, **TikTok**, **Instagram**, and HTML5 video players.
- Multi-resolution selector: **Best Quality (4K/1080p)**, **1080p Full HD**, **720p HD**, **480p Standard**, and **🎵 Audio Only (320k MP3)**.
- Full anti-bot cookie and session handoff ensures private or authenticated videos download seamlessly.

#### 5. 🚀 16-Connection Parallel Turbo Core & Auto-Updaters
- Multi-threaded segmented chunk streaming powered by an optimized `aria2c` core.
- Hands-off daily background update checks for `yt-dlp` media extraction.
- Single-file Fluent setup wizard (`FastDownloader-Setup.exe`).
