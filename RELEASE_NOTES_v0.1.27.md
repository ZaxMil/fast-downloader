# FastDownloader Pro v0.1.27 — Compact Desktop UI

This release makes the approved compact desktop design available through the existing in-app updater.

## What's new
- Compact, space-efficient dashboard with an integrated title and download counts.
- Dense task list with live progress, speed, queue, status, and file actions.
- Refined left navigation, compact toolbar, and light/dark appearance.
- Ctrl+F focuses the download list search field.
- Preserves Arabic right-to-left, filter and column customization, existing downloads, browser integration, and update controls.

## Update safety
- The installed app updater verifies SHA-256 asset hashes, downloads changed UI/extension packages where necessary, and preserves the rollback/restart checks.
- Active file and video downloads must be paused or completed before the updater restarts the app.
- No download engine changes in this release.
