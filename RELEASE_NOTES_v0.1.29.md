# FastDownloader Pro v0.1.29 — Compact Polish V2

A focused visual update to the standalone desktop download manager. Download engines and task operations are unchanged.

- Keep the app name in the native window title only; keep one small app mark in the toolbar.
- Reduce top-right controls to five compact items: theme, language, engine/update status, columns, and more.
- Move notification muting, toolbar customization, and support into the small More menu without deleting functionality.
- Make the main theme switch reliably alternate between Light and Dark. The existing legacy ZaxCore theme remains selectable in View.
- Fix light-theme context menus that incorrectly used a forced dark background. Match menu text, contrast, borders, and switches to the active theme.
- Remove button rotation, hovering translation, heavy glowing, and playful movement. Quiet background/border changes remain.
- Tighten toolbar, context bar, sidebar, and column menus; no extra browser tabs or shell changes.
- Preserve download tasks, browser integration, the updater, columns, filters, and RTL support.

To upgrade, pause active downloads and choose **Check Updates** then **Install & Restart App Now**. No clean reinstall is required.

The updater's checksum validation, changed-package selection, restart verification and rollback remain in place.
